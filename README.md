# Iconos Demo

Aplicacion Flutter de ejemplo con navegacion inferior entre **Peoples**, **Chats** y **Calls**.

## Funciones

- Tema oscuro.
- Lista simulada de contactos y llamadas.
- Alta de contactos mientras la aplicacion esta abierta.
- Creacion de conversaciones simuladas a partir de un contacto.

Los datos de ejemplo no se guardan al cerrar la aplicacion.

## Ejecutar en Chrome

Instala Flutter y, desde esta carpeta, ejecuta:

```powershell
flutter pub get
flutter run -d chrome
```

## Verificaciones

```powershell
flutter analyze
flutter test
```
